# Sanwo for .NET

Sanwo payment SDK for ASP.NET — one interface for every payment provider.

> **Full documentation at [docs.sanwo.dev](https://docs.sanwo.dev/sdks/dotnet/)** — guides, examples, and API reference for every SDK and provider.

## Install

```bash
dotnet add package Sanwo
```
